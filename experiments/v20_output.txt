E4  THEOREM 1: THE SYMMETRY FLOOR FOR TRANSLATION-COVARIANT MAPS
==============================================================================
  If F_f commutes with the fine octave shift U_f (exact on the sync ring)
  and R U_f = S R (S = coarse one-node shift), then for every m and phase:
    R F_f^m - c F_c R  -  S (R F_f^m - c F_c R) U_f^dag  =  c (S F_c S^dag - F_c) R
  so delta >= ||(S F_c S^dag - F_c) R||_F / (2 sqrt(||R F^m||^2+||F_c R||^2)).
  For a co-isometric R (R R^dag = 1) the floor is R-independent:
    delta >= ||S F_c S^dag - F_c||_F / (2 sqrt(2 N_c))  for ALL m.
    n_c = 1: floor(F) = 0.4996   floor(T) ~ 0.4999
    n_c = 2: floor(F) = 0.5004   floor(T) ~ 0.5004
    n_c = 3: floor(F) = 0.4976   floor(T) ~ 0.4975
    n_c = 4: floor(F) = 0.4975   floor(T) ~ 0.4974
  verified on 36 translation-covariant maps x 8 m (sync ring n_c=2): min(delta - floor) = 0.3632  (>= 0 required)
  the floor is m-independent: no time dilation m can rescue any translation-covariant octave-to-station map.
